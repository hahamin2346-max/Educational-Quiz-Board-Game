# 🎲 문제 소유 보드게임

모둠끼리 보드판을 돌며 문제를 풀고, 가장 먼저 맞힌 칸의 **땅 주인**이 되어 점수를 겨루는 수업용 보드게임입니다.
설치 없이 브라우저(크롬 또는 엣지 권장)에서 파일을 더블클릭하면 실행됩니다.

## 파일 구성

| 파일 | 하는 일 |
| --- | --- |
| `setup.html` | 선생님이 **문제와 점수 등을 입력**하는 설정 페이지 |
| `game.json` | 입력한 내용이 저장된 **설정 파일** (문제집 파일) |
| `index.html` | 수업 시간에 학생들에게 보여주는 **게임 화면** |

> JSON은 문제, 정답, 점수 같은 설정을 담아 두는 메모장 같은 파일입니다. 직접 읽거나 고칠 필요는 없습니다.

## 1. 수업 전: 문제 입력 (선생님)

1. `setup.html`을 더블클릭해 엽니다.
2. **기본 설정**에서 게임 제목과 **전체 게임 시간**(기본 20분)을 정합니다.
3. **모둠 이름**과 **점수 규칙**을 필요하면 바꿉니다. (그대로 두어도 됩니다.)
4. **칸별 문제**에서 각 칸의 **이름**과 **문제 3개 + 정답**을 입력합니다.
   - 칸 제목 줄에서 바로 칸 이름을 입력할 수 있습니다. 이름은 보드판과 모둠별 "소유한 땅" 목록에 표시됩니다.
   - 엑셀·구글 시트에서 `칸번호 / 문제 / 정답` 3열을 복사해 **문제 일괄 붙여넣기**에 붙여넣고 [추가]를 눌러도 됩니다.
   - 연습용으로 맨 위 [샘플 채우기]를 사용할 수 있습니다.
5. 맨 위 **[game.json 저장]**을 누릅니다.
   - 폴더 선택 창이 한 번 뜹니다. `index.html`이 있는 폴더를 고르면 그 폴더에 `game.json`이 바로 저장됩니다. (기존 파일은 덮어씁니다.)
   - 폴더 저장을 지원하지 않는 브라우저에서는 다운로드로 저장됩니다.
   - 입력하던 내용은 브라우저에 임시 저장되어, 창을 닫았다 열어도 이어서 작성할 수 있습니다.

이미 만든 설정을 고치려면 설정 페이지의 [JSON 불러오기]로 `game.json`을 열어 수정한 뒤 다시 저장합니다.

### 보드 구성 (20칸 고정)

| 칸 | 개수 | 설명 |
| --- | --- | --- |
| 출발 (0번) | 1 | 문제 없음, 쉬어가는 칸 |
| 문제 칸 | 16 | 칸마다 문제 3개 |
| 🔑 황금열쇠 (5·10·15번) | 3 | 도착하면 +2점 (아래 참고) |

## 2. 수업 시간: 게임 진행

1. `index.html`을 열어 교실 화면(TV·전자칠판)에 띄웁니다.
2. "설정 파일이 필요합니다" 화면이 나오면 **[game.json 불러오기]**로 파일을 선택합니다.
3. 1모둠 차례부터 시작합니다. 한 차례의 흐름은 다음과 같습니다.
   1. 해당 모둠이 **실제 주사위**(1~6)를 굴립니다.
   2. 화면의 **숫자 버튼(1~6)** 중 나온 눈을 누르면 말이 **시계 방향**으로 이동합니다.
   3. 도착한 칸의 문제가 나타납니다. 모둠이 답하면 선생님이 [정답 보기]로 확인하고 **⭕ 정답** 또는 **❌ 오답**을 누릅니다.
   4. 정답·오답 어느 쪽이든 판정 후 **문제와 정답이 화면에 공개**됩니다.
   5. **[다음 모둠]**을 눌러 넘깁니다.

### 화면 위쪽 버튼

| 버튼 | 기능 |
| --- | --- |
| 남은 시간 ▶/⏸ | 전체 게임 시간. **첫 주사위를 누르면 자동 시작**, ⏸로 잠시 멈출 수 있음 |
| ↶ 되돌리기 | 직전 동작 취소 (여러 번 가능, 남은 시간은 되돌아가지 않음) |
| 게임 종료 | 지금 바로 끝내고 순위 확인 |
| 설정 JSON 변경 | 다른 `game.json`으로 교체 (게임 초기화됨) |
| 게임 초기화 | 점수·소유 정보를 모두 지우고 처음부터 다시 시작 |

### 알아두세요

- 새로고침하거나 창을 닫았다 열어도 점수, 진행 상황, 남은 시간이 유지됩니다. 처음부터 하려면 **[게임 초기화]**를 누르세요.
- 진행 상황은 **그 컴퓨터의 그 브라우저**에 저장됩니다. 다른 컴퓨터나 브라우저에서는 새로 시작합니다.
- `game.json`을 새로 저장했다면 게임 화면에서 [게임 초기화]를 한 번 눌러야 반영됩니다.

## 3. 게임 규칙

### 목표

제한 시간 동안 문제를 많이 맞혀 **가장 높은 점수**를 얻는 모둠이 우승합니다.
어떤 칸의 문제를 가장 먼저 맞히면 그 칸의 **땅 주인**이 됩니다.

### 진행

- 4개 모둠이 차례대로 진행하며, 모두 출발 칸에서 시작합니다.
- 칸마다 문제가 3개이고, 도착할 때마다 순서대로 하나씩 풉니다.
- **한 번 나온 문제는 정답이든 오답이든 다시 나오지 않습니다.** (사용된 문제는 비활성화)
- 출발 칸, 문제가 없는 칸, 문제가 모두 소진되었지만 주인이 없는 칸에서는 아무 일도 없이 쉬어갑니다.

### 점수표 (기본값)

| 상황 | 점수 |
| --- | --- |
| 그 칸에서 **처음으로 정답**을 맞힘 | **+5점**, 그리고 그 칸의 **땅 소유** |
| 이후 정답을 맞힘 | **+3점** (땅 소유 없음) |
| 문제를 틀림 | **-1점** (문제는 사라짐) |
| 문제가 모두 소진된 칸에 도착 - **내 땅** | **+1점** |
| 문제가 모두 소진된 칸에 도착 - **남의 땅** | **-1점** (통행료) |

- 점수는 0점 아래로 내려가지 않습니다.
- 한 번 정해진 땅 주인은 바뀌지 않습니다.
- 앞선 문제를 틀렸다면, 그 칸에서 처음으로 정답을 맞힌 모둠이 땅 주인이 됩니다.
- 점수 규칙은 설정 페이지에서 바꿀 수 있습니다.

### 🔑 황금열쇠

도착하면 **+2점**을 받고 끝납니다. 이벤트는 웹이 아닌 현실에서 직접 진행합니다.
점수는 `index.html`의 `KEY_POINTS`에서 바꿀 수 있습니다.

### 화면 읽는 법

- **칸 테두리와 모서리 색**: 땅을 소유한 모둠의 색
- **칸의 동그라미 3개**: 문제 상태. 모둠 색은 그 모둠이 맞힌 문제, 회색은 틀려서 소진된 문제
- **색깔 동그라미 숫자**: 모둠의 말. 노란 테두리는 현재 차례인 모둠의 위치
- **보드판 아래 모둠 카드**: 모둠별 점수, 소유한 땅 수, 현재 위치, 소유한 땅 이름 목록

### 종료와 순위

- **남은 시간이 0이 되면 알림음과 함께 바로 종료**됩니다. (풀던 문제가 있어도 종료)
- 순위는 **점수 순**이고, 같으면 **소유한 땅이 많은 모둠**이 앞섭니다.
- 다시 하려면 **[게임 초기화]**를 누르세요.
