🎲 문제 소유 보드게임 사용법

1. 게임 설정하고 시작하는 법

먼저, 파일 3개만 알면 됩니다

파일하는 일
setup.html선생님이 문제와 점수 등을 입력하는 페이지
game.json입력한 내용이 저장된 설정 파일
index.html수업 시간에 학생들에게 보여주는 실제 게임 화면
JSON(제이슨)이 뭔가요?
문제, 정답, 점수 같은 설정을 담아 두는 메모장 같은 파일입니다. 내용을 직접 읽거나 고칠 필요는 없습니다. 설정 페이지에서 [저장] 버튼을 누르면 자동으로 만들어지고, 게임 화면에서 [불러오기]만 하면 됩니다. "문제집 파일"이라고 생각하시면 됩니다.

모든 페이지는 파일을 더블클릭하면 인터넷 브라우저(크롬 또는 엣지 권장)에서 열립니다. 설치는 필요 없습니다.

① 문제 입력하기 (수업 전, 선생님)

  1. setup.html을 더블클릭해서 엽니다.
  2. 기본 설정에서 게임 제목, 보드 크기, 전체 게임 시간(기본 20분)을 정합니다. 보드 크기를 바꾸면 칸 수가 자동으로 계산됩니다. (가로 8 × 세로 6 = 테두리 24칸)
  3. 모둠 이름과 점수 규칙을 필요하면 바꿉니다. (그대로 두어도 됩니다.)
  4. 칸별 문제에서 칸 번호를 눌러 펼친 뒤, 칸마다 문제 3개와 정답을 입력합니다.
    • 0번은 출발 칸이라 문제가 없습니다.
    • 엑셀이나 구글 시트에 칸번호 / 문제 / 정답 3열로 정리해 두었다면, 복사해서 "문제 일괄 붙여넣기"에 붙여넣고 [추가]를 누르면 한 번에 들어갑니다.
    • 연습해 보고 싶다면 맨 위 [샘플 채우기] 버튼을 눌러 보세요.
  5. 입력이 끝나면 맨 위 [game.json 저장] 버튼을 누릅니다. 파일이 컴퓨터(보통 '다운로드' 폴더)에 저장됩니다.
    입력하던 내용은 브라우저에 임시 저장되어, 창을 닫았다가 다시 열어도 이어서 작성할 수 있습니다.
  6. 저장한 game.json을 이 폴더에 넣어 두면 찾기 편합니다. (기존 파일은 덮어써도 됩니다.)

이미 만든 설정을 고치고 싶다면 설정 페이지 위쪽의 [JSON 불러오기]로 game.json을 열어 수정한 뒤 다시 저장하면 됩니다.

② 게임 시작하기 (수업 시간)

  1. index.html을 더블클릭해서 엽니다. 교실 화면(TV·전자칠판)에 띄우세요.
  2. "설정 파일이 필요합니다" 화면에서 [game.json 불러오기]를 누르고 game.json을 선택합니다.
  3. 보드판이 나타나면 준비 끝입니다. 1모둠 차례부터 시작합니다.

③ 게임 진행 방법 (선생님이 조작)

  1. 해당 모둠이 실제 주사위를 굴립니다.
  2. 화면의 숫자 버튼(1~12) 중 나온 눈의 수를 누르면 말이 시계 방향으로 움직입니다. (주사위 2개를 굴렸다면 합계를 누르세요.)
  3. 도착한 칸의 문제가 화면에 나타납니다. 모둠이 답하면 선생님이 [정답 보기]로 정답을 확인하고 ⭕ 정답 또는 ❌ 오답을 누릅니다.
  4. 결과가 표시되면 [다음 모둠]을 눌러 다음 모둠으로 넘깁니다.

화면 위쪽 버튼

버튼기능
남은 시간 ▶/⏸전체 게임 시간입니다. 첫 주사위를 누르면 자동 시작됩니다. 설명할 때는 ⏸로 잠시 멈출 수 있습니다.
↶ 되돌리기잘못 눌렀을 때 직전 동작을 취소합니다. (여러 번 가능, 남은 시간은 되돌아가지 않음)
게임 종료시간이 남아도 지금 바로 끝내고 순위를 봅니다.
설정 JSON 변경다른 game.json으로 바꿉니다. (게임이 초기화됩니다.)
게임 초기화점수·소유 정보를 모두 지우고 처음부터 다시 시작합니다.
알아두세요
  • 게임 중 새로고침하거나 창을 닫았다 열어도 점수와 진행 상황, 남은 시간이 그대로 유지됩니다. 처음으로 돌아가려면 [게임 초기화]를 눌러야만 합니다.
  • 진행 상황은 그 컴퓨터의 그 브라우저에 저장됩니다. 다른 컴퓨터나 다른 브라우저로 열면 새로 시작해야 합니다.
  • 다음 수업에서 같은 반으로 이어 하려면 같은 컴퓨터, 같은 브라우저로 열어 주세요.

2. 게임 규칙

목표

제한 시간(기본 20분) 동안 문제를 많이 맞혀 가장 높은 점수를 얻는 모둠이 우승합니다. 문제를 맞히면 점수를 얻고, 가장 먼저 맞힌 모둠은 그 칸의 땅 주인이 됩니다.

기본 진행

  • 4개 모둠이 차례대로 진행합니다. 모두 출발 칸에서 시작합니다.
  • 차례가 오면 실제 주사위를 굴려 나온 수만큼 보드판을 시계 방향으로 이동합니다.
  • 도착한 칸에 있는 문제를 풉니다. 한 칸에는 문제가 3개 있고, 순서대로 하나씩 풀립니다.
  • 같은 칸에 여러 번 올 수 있습니다. 문제가 남아 있으면 남은 문제를 풀어 또 점수를 받을 수 있습니다.
  • 출발 칸과 문제가 없는 칸에서는 아무 일도 일어나지 않고 쉬어갑니다.

점수표

상황점수
그 칸의 첫 번째 문제를 맞힘+5점 그리고 그 칸의 땅 소유
그 칸의 두 번째·세 번째 문제를 맞힘+3점 (땅 소유는 없음)
문제를 틀림-1점 (문제는 그대로 남음)
문제 3개가 모두 풀린 칸에 도착 - 내 땅+1점
문제 3개가 모두 풀린 칸에 도착 - 남의 땅-1점
  • 점수는 0점 아래로 내려가지 않습니다.
  • 땅의 주인은 바뀌지 않습니다. 같은 칸에서 한 번 소유가 정해지면 끝까지 유지됩니다.
  • 땅 주인이 자기 땅에 다시 와도 문제가 남아 있으면 똑같이 풀고 점수(+3점)를 받습니다.
  • 틀린 문제는 사라지지 않고 그대로 남습니다. 다음에 그 칸에 오는 모둠이 같은 문제를 풉니다.

화면 읽는 법

  • 칸 테두리와 모서리 색: 그 땅을 소유한 모둠의 색입니다.
  • 칸의 동그라미 3개: 문제 3개의 상태입니다. 색이 칠해진 것은 그 모둠이 맞힌 문제입니다.
  • 색깔 동그라미 숫자: 모둠의 말입니다. 노란 테두리는 지금 차례인 모둠의 위치입니다.
  • 오른쪽 점수판: 모둠별 점수, 소유한 땅 수, 현재 위치입니다.

게임 종료와 순위

  • 남은 시간이 0이 되면 알림음이 울리며 바로 게임이 끝납니다. (풀던 문제가 있어도 종료됩니다.)
  • 순위는 점수가 높은 순입니다. 점수가 같으면 소유한 땅이 많은 모둠이 앞섭니다.
  • 결산 화면에 모둠별 순위, 점수, 땅 개수가 표시됩니다.
  • 다시 하려면 [게임 초기화]를 누르세요.
